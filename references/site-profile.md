# Site Profile

Load this reference only when missing project/site context can materially change the result.

## Gather context efficiently

If a connected site is available, inspect discoverable facts first. Ask only for facts that remain unknown and decision-relevant. Do not request a complete plugin inventory when only one task surface matters.

Potential inputs include:

| Input | Ask only when it changes |
|---|---|
| Active theme / child theme | theme-owned layout, Site Editor availability, hooks/facilities, compatibility |
| Editing model | Gutenberg, block theme/Site Editor, page builder, template ownership, manual output format |
| Relevant active plugins/workloads | implementation capability, reuse vs replacement, WooCommerce/forms/ACF/multilingual/SEO/performance behavior |
| Content/data model | post type, taxonomy, fields/ACF, product/catalog structure, reusable/global content ownership |
| Connected abilities | whether the requested mechanism can be inspected/applied through available native/plugin/Bridge capabilities |
| Site purpose / audience | information architecture, tone, conversion priority, or content hierarchy |
| Language and RTL/LTR | layout direction, icon placement, typography, or responsive behavior |
| Visual direction | composition, density, shape language, imagery, or interaction style |
| Brand colors/tokens | color system or component styling |
| Container model | full-width vs boxed behavior and section geometry |
| Page goal / CTA | hierarchy, section order, and conversion flow |
| Required content/sections | actual page structure |
| Reference sites/images | visual interpretation when text direction is insufficient |

Do not ask for every field. Skip anything already provided, safely discoverable, or irrelevant to the requested work.

## Preserve project-specific state

Treat project-specific theme/builder/plugin choices, colors, URLs, IDs, content types, data models, and brand rules as site context, not global Skill defaults. Never carry them into an unrelated site unless the user explicitly supplies them again as applicable context.
